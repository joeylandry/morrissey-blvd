# Morrissey Blvd

The band's website: full-screen sections with a torn-paper page turn, tour dates, music, video, a photo pile, and the merch store (live from Shopify).

```bash
npm install
npm run dev
```

- Content (shows, releases, videos, photos, bio): `src/data/site.ts`
- Photos go in `public/photos/` and get listed in `photos` in `src/data/site.ts`
- Store products are read from the Shopify store and refresh hourly; checkout happens on Shopify
- Paper/grain textures are generated by `node scripts/textures.mjs`
